# week4-mortgageRepaymentCalculator
A simple web-based mortgage calculator that lets users enter a loan amount, term, and interest rate to see their monthly and total repayments.

## Features
- Enter mortgage amount, term, and interest rate  
- Choose between repayment or interest-only type  
- Instantly calculates monthly and total repayment amounts  
- Clean, responsive layout built with HTML, CSS, and JavaScript

## How to Use
1. Fill in the mortgage amount, term, and interest rate  
2. Select the mortgage type  
3. Click **Calculate Repayments** to view your results  
4. Use **Clear All** to reset the form
